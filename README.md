# LocalVibe

**Every Product Deserves a Platform....**

LocalVibe is a simple first-year student project. It is a small online marketplace where local vendors can add products and customers can browse and place demo orders.

## Project files
- `index.html` - website structure
- `style.css` - website design and colours
- `script.js` - buttons, vendor login, products, cart and orders

## How to run
Open `index.html` in a web browser.

This is a front-end college demo. Information is saved in the browser using localStorage. It does not use a real database or collect real payments. Vendor login is only a demonstration and should not be used with a real password.
